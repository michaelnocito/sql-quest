- **[P1] Flatten the beginner difficulty curve — 3 waves → 9-wave ramp** (2026-05-28) — Mike: the knowledge ramps too fast; this is a track for someone who's never touched SQL, learning entry-level analyst skills. The old SELECT → WHERE → JOIN over three waves was way too steep (especially the jump straight to JOIN). Re-paced to **one genuinely new idea per wave**, building single-table fluency before JOIN: **1 SELECT \*** → **2 SELECT specific columns** → **3 WHERE (text =)** → **4 WHERE (number >, comparison ops)** → **5 AND** → **6 OR** → **7 ORDER BY** → **8 LIMIT (top N)** → **9 JOIN**. Each wave layers earlier verbs and carries a `reinforces` recall chip on expanding gaps. **Engine change:** result comparison is order-insensitive by default, but now order-SENSITIVE when the solution uses `ORDER BY` (`sameResult(a,b,ordered)`, `ordered = /\border by\b/i.test(solution)`), so sorting/top-N waves are actually testable. Verified all 9 solutions + wrong-answer cases in-browser.

Grew `#sql` to min-height 156px, font 15.5px / line-height 1.7, roomier padding (ghost overlay kept in sync). Much easier to read and write queries.
