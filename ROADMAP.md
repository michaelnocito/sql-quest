## Shipped
- **[P1] Advanced enemy mechanic — telegraphed charged strike** (2026-05-28) — richer than "wrong = a little damage." Raiders and Wardens *wind up* over consecutive wrong queries; the turn before they unleash, a pulsing yellow warning ring + ⚡ telegraphs the heavy hit on that foe (and the feedback line warns "Charged strike incoming"). The charged strike hits hard (Raider 13, Warden 18 vs. their 6/8 normal) with a thicker gold bolt and a bigger base flash. **A correct query always interrupts the wind-up** (resets charge) — good play stays safe, so the pressure only builds when you keep missing the concept. Scouts never charge (pure light chip, 4). All per-archetype data in `ENEMY_ARCH`.
- **[P2] Distinct enemy archetypes** (2026-05-28) — each wave's foes now read as a distinct silhouette instead of one shared shape: **Scouts** (nimble 3-point cyan shards, fast spin), **Raiders** (5-point red stars), **Wardens** (heavy 6-point violet crystals, slow spin). Data-driven via an `enemyArch` field per wave + an `ENEMY_ARCH` config map; halos/strokes/nuclei recolored per type, `.mote-core` hit-flash preserved. W1 scout / W2 raider / W3 warden.
- **[P1] Geometric/psychedelic celestial characters** (2026-05-28) — replaced the placeholder Spire and plain circular void-motes with synthetic geometric "celestial being" forms. **Hero = the Oracle**: a pulsing aura, a slow-rotating 6-point starburst halo with radial spokes, a counter-rotating orbit ring with nodes, an inner hexagon, and a glowing core (still `#base-core` for the hit-flash). **Enemies = void-beings**: a slow-rotating dark crystal star (6-spike) with a counter-rotating inner triangle glyph and a red nucleus (still `.mote-core` for the hit-flash; name now sits below). Idle motion is CSS (`prefers-reduced-motion` respected); the spin resets coincide with turn redraws, which are masked by the combat FX. Renamed on-field copy Spire→Oracle. Next: distinct enemy archetypes.
- **[P1] Psychedelic-celestial ambient backdrop** (2026-05-28) — locked the art direction as **psychedelic celestial** (synthetic geometric SVG/CSS, art-first, hypnotic, low cognitive load) — chose this over using hand-drawn charcoal art. Added a **persistent `#field-bg` layer** (built once, so its motion never restarts on a turn redraw) stacked behind the transparent gameplay `#field`: slow-drifting nebula blobs, twinkling starfield, a faint slow-rotating **sacred-geometry mandala** (rings + spokes + counter-rotating hexagon/triangle), and a gentle full-layer hue drift. All CSS animation (SMIL doesn't start when injected via innerHTML in Chromium) + `prefers-reduced-motion` respected. Next lever: geometric/psychedelic **character** forms for hero + enemies.
- **[P2] Music funk/oomph pass** (2026-05-28) — Mike: "kick it up… more oomph… a funky vibe, a little 70s Super Fly-ish, but not too much — without losing the researched calm/spatial benefits." Added a `groove:true` per-section flag: grooved (energetic) bars get a 70s-soul funk layer — syncopated plucky bass riff (root/push/5th-ghost/octave), off-beat square clav stab, soft shaker/hi-hat (accented off-beats) — plus a 7th chord-color tone. Intro/bridge/calm-reprise (arp none/sparse) stay ungrooved = pure ambient, preserving the calm. Tempo unchanged (~70 BPM). Still 100% procedural Web Audio, no assets; song still ~5 min / 88 bars.
- **[P1] Celestial Cartographer theme — battlefield reskin** (2026-05-28) — chosen art-first theme that broadens appeal beyond "young boys" (research: Monument Valley/Hades/Stardew — beauty + inclusive characters + awe over domination; audience is adult, near gender-balanced analysts). Combat/play unchanged (the FF part Mike wanted to keep). Battlefield is now a twilight-sky window: indigo→teal sky gradient, two nebulae, a 64-point starfield (data points), a glowing **Spire** (your star-anchor) replacing the turret, and enemies reskinned as **void-motes** (dark eclipse cores with red halos — threat still red-coded). Field-pane bg matched to the sky so it's seamless. All SVG/CSS, no asset files. Copy lightly rethemed ("void-motes drifting toward the Spire"). Deeper narrative retheme (wave briefings, splash tagline, naming) still TODO.
- **[P1] Enemy counterattack — FF turn exchange** (2026-05-28) — pushing toward the FF4/FF7 vibe: a **wrong (valid-but-wrong) query now lets the swarm hit back**. The frontmost living enemy lunges and fires a red bolt at the base, the base core flashes, a floating "-6" pops, and base HP drops (`ENEMY_HIT_DMG=6`, per-wave overridable via `enemyDmg`). Correct queries still only damage enemies; **syntax errors / banned verbs stay damage-free** (deliberate — don't punish typos while learning). Over-broad queries take the counterattack + friendly fire. Next, more advanced enemy mechanics (TBD by Mike).
- **[P1] Spaced-retrieval foundation** (2026-05-28) — learning-science request: bring earlier concepts back after a gap, interleaved, so the player *recalls* them. Two data-driven levers: (1) solutions are layered so later waves reuse earlier verbs; (2) a `reinforces: [...]` field per wave drives a yellow **"🔁 Recall drill — this wave makes you reuse: …"** chip in the briefing. W1 none, W2 SELECT, W3 SELECT+WHERE. Expanding-gap review schedule (~1/3/7 waves) documented in waves.js for when 4–7 are authored. Chose this over Training-Ground-only (voluntary review is weak) and adaptive (overkill for prototype) — both roadmapped.
- **[P2] Music variety — ~5 min through-composed track** (2026-05-28) — replaced the 4-bar Am–F–C–G loop with a 12-section `SONG` (~88 bars / 4.99 min before repeat): varied progressions, arpeggio shapes (up/down/updown/sparse/none), dynamics, and optional bass pulse. Still 100% procedural Web Audio, no assets. Goal is ~10 min — extension roadmapped.
- **[P1] Start splash + build timestamp + background music** (2026-05-28) — start screen (title, tagline, "Start Campaign", build stamp in Eastern 12-hour time, e.g. `May 28, 2026 · 6:54 PM ET` via `BUILD_TS` const — update each build). Starting the campaign is the audio-unlock gesture and kicks off a looping procedural ambient track (Am–F–C–G pad + bass + arpeggio, synthesised in Web Audio, no asset files). Speaker button mutes/unmutes. Also resumes AudioContext for iOS/Safari.
- **[P0] Layout: keep the action always visible** (2026-05-28) — the result table was shoving the battlefield below the fold. Reworked to a turn-based-combat layout: battlefield pinned on top (mobile) / full-height right panel (desktop ≥900px) with the command console scrolling independently. Result table capped + scrolls inside the console; the fight is never covered.
- **[P1] FF-style HP-whittle combat exchange** (2026-05-28) — enemies have HP bars; a correct query is a volley chipping `maxHp/rounds` per turn, so you re-fire the right query a few times to clear (drilling the syntax). All living enemies creep forward slowly (visible, near-harmless early). Wrong query = wasted turn + free creep; over-broad query = friendly-fire base damage. Floating damage numbers + non-lethal hit flash. Tuning is data-driven per wave (`rounds`, `creep` in waves.js).
- **[P1] Explosion/attack animation on correct query** (2026-05-28) — staggered beams from the base, per-enemy detonation (flash + expanding ring + 7 shards), enemy death fade. Real visual payoff before the Wave Cleared card.
